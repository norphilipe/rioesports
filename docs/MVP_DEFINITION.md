# RIO ESPORTS MVP Definition

The first production MVP is considered complete when a verified player can:

1. Create and access an account.
2. Maintain a competitive player profile.
3. Verify Steam identity.
4. Join and leave an eligible competitive queue.
5. Be matched into a competitive match.
6. Receive a server assignment and match lifecycle state.
7. Have a completed result recorded.
8. Receive a ranking/MMR update.

FACEIT and Leetify enrich competitive confidence but must not block the basic MVP when their external credentials are unavailable.
